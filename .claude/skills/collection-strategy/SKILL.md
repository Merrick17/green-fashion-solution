# Collection Strategy Skill

Use when admin structures a proposal or designer organizes a collection.

## Standard Collection Section Order

For a full sourcing collection, follow this section sequence:

1. **Cover** — season, brand, creative direction tagline
2. **Creative Direction** — mood, color story (named palette), texture language, silhouette family
3. **Outerwear** — coats, jackets, blazers (lead section — highest impact, sets the tone)
4. **Knitwear** — sweaters, cardigans, knit tops (if AW/Resort — move to #3 for cold-weather collections)
5. **Tops & Shirting** — blouses, shirts, T-shirts, bodysuits
6. **Bottoms** — trousers, skirts, shorts
7. **Denim** (if applicable) — jeans, denim jackets, denim coordinates
8. **Accessories** (if applicable) — scarves, belts, hats, bags

For limited-scope proposals (e.g. "tops-only"), only include the relevant sections.

## Section Visual Weight

Within each category section:
- **hero** — 1 item maximum, the strongest statement piece for this category
- **secondary** — 2-3 supporting options with clear differentiation (silhouette, color, or construction)
- **accent** — 1-2 detail or contrast pieces (a print, a trim, an unusual fabrication)

## Fabric-to-Garment Mapping

| Fabric direction | Best categories |
|-----------------|----------------|
| Linen / linen-cotton | Tops, trousers, outerwear, resort |
| Wool / flannel | Outerwear, knitwear, tailoring (AW) |
| Silk / silk-satin | Tops, eveningwear, blouses |
| Cotton jersey / interlock | Basics, t-shirts, casual tops |
| Denim | Bottoms, jackets, coordinates |
| Cashmere / merino | Knitwear |
| Nylon / technical | Outerwear, activewear |
| Lace / eyelet | Detail, resort tops, occasion |

## Coherence Rules

- Color story should thread through ALL sections (use 2-3 common palette anchors across sections)
- Fabric families should feel intentional — avoid random materials in a single collection
- Each section needs at minimum: 1 hero + 1 secondary asset
- unmetRequirements in the proposal signals what still needs commissioning — always fill this field if any category is underpopulated
